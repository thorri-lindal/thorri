## 📚 Free Beginner Resources (HTML, CSS & JS)  
- 📖 [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Learn) – Your best friend for web dev fundamentals  
- 🌍 [Web.dev](https://web.dev/learn/) – Guides by Google on accessibility, responsive design & more  
- 📘 [Eloquent JavaScript](https://eloquentjavascript.net/Eloquent_JavaScript.pdf) – A modern introduction to JavaScript  
- 📝 [JavaScript.info](https://javascript.info/) – Solid JS tutorial covering core concepts  
- 🎯 [Flukeout](https://flukeout.github.io/) – Learn CSS selectors quickly  
- 🐸 [Flexbox Froggy](https://flexboxfroggy.com/) – Master flexbox through a fun game  
- 🌱 [CSS Grid Garden](https://cssgridgarden.com/) – Learn CSS grid with interactive lessons  
- 🛤 [Roadmap.sh](https://roadmap.sh/roadmaps?g=Web+Development) – Beginner-friendly roadmap to guide your journey  

## 🖥 Backend Language Resources

- 🐘 [PHP Tutorial](https://www.phptutorial.net) – Step-by-step PHP learning  
- ☕ [Java Tutorial](https://dev.java/learn/) – Official Java learning path  
- 🐍 [Python & Go](https://rentry.org/htbby) – Resource hub for Python & Go
