### **📂 File & Directory Management**

- `dust` – Better `du`, shows disk usage with intuitive visualization
- `tree` – Displays directories as a tree structure
- `trash` – Safer alternative to `rm`, moves files to the trash instead of deleting
- `mmv` – Batch rename, move, or copy files with patterns
- `rename` – Rename files in bulk using regex
- `dtrx` – Extracts any compressed file type without needing specific commands

### **🔍 Searching & Navigation**

- `dog` – Faster alternative to `dig` for DNS lookup
- `ag` – "The Silver Searcher," an ultra-fast text searching tool
- `pt` – "The Platinum Searcher," similar to `ag` but even faster
- `lsd` – Better `ls` with icons, colors, and better readability
- `broot` – A powerful interactive directory navigator

### **📦 Data & Archiving**

- `zstd` – Super-fast compression algorithm
- `xz` – Compression tool, alternative to gzip/bzip2
- `unar` – Extracts `.zip`, `.rar`, `.7z`, and more
- `pigz` – Multithreaded gzip, much faster than `gzip`
- `pv` – Monitor progress of data through a pipeline

### **⚡ Productivity & Automation**

- `taskwarrior` – CLI-based task manager

- `entr` – Another tool to trigger commands on file change
- `timewarrior` – Time-tracking tool
- `mprocs` – Run multiple processes in a single terminal window
